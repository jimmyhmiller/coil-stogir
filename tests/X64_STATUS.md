# Test status for the x86-64 port

Generated by `tools/x86/test-status.py`; edit the tables there, not here.
`tools/x86/family-tests.sh FAMILY` prints the test paths of one family.

## Categories

| Category | Tests | Meaning |
|---|---|---|
| neutral-IR | 84 | Graph, analysis and optimizer tests with no backend, JIT or object import. Target-independent. |
| ported-to-facade | 156 | Import `stogir.native.compile` / `stogir.native.private-leaf` / `stogir.jit.native`. Must pass on both hosts; the gate for the x86-64 backend. |
| a64-internal | 125 | AArch64 backend internals, hand-encoded AArch64 code, or Mach-O. Not expected to run on x86-64. |
| x64-internal | 29 | x86-64 backend internals (`tests/x64-FAMILY-*.coil`), tested directly against `stogir.x64.*`. Run on the x86-64 host; they skip or check selection only elsewhere. |
| link-partner | 74 | Links objects that a generator test wrote to /tmp; runs with `--link-flag` (README). Works on Linux once its generators pass there. |
| host-layer | 10 | Image, JIT and object-writer layers below the backend, including the `x64-*` encoder, image and link tests. |

## Families of the ported tests

The family is the operation family whose x86-64 implementation the test mainly
waits for. Most tests also need the phase-1 core (integer values, parameters,
compares, branches, PHIs) and many need calls for their harness.

| Family | Tests |
|---|---|
| integer | 30 |
| memory+stack | 19 |
| calls+ABI | 25 |
| floating | 13 |
| vector | 7 |
| switch+control | 14 |
| atomics | 1 |
| private-leaf/module | 1 |
| inlining/optimizer | 39 |
| other | 7 |

28 ported tests keep AArch64 instruction-shape checks behind
`(target/arch-pick CHECK (do))`: they check behavior on x86-64 and behavior plus
shape on AArch64. An x86-64 shape check can take the place of `(do)`.
